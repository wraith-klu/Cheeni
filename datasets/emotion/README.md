# Cheeni Emotion & Mood Dataset (Cap 3)

### Supported Datasets:
- **RAVDESS**: 7,356 speech files (8 emotions: calm, happy, sad, angry, fearful, surprise, disgust, neutral).
  Download: https://zenodo.org/record/1188976
- **CREMA-D**: 7,442 clips with audio-visual emotional validation.
  Download: https://github.com/CheyneyComputerScience/CREMA-D

Extract audio files into `datasets/emotion/wavs/` and place `metadata.csv` here.
